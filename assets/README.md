# UI resources

Geist Regular, Medium and SemiBold are from the [official Geist repository](https://github.com/vercel/geist-font). The SIL Open Font License is included in `fonts/OFL.txt`. Fonts are bundled privately with DeskDots; no system font installation is performed. Microsoft YaHei UI provides Chinese glyph fallback.

The regular icons are from [Phosphor Icons](https://github.com/phosphor-icons/core). Their MIT license is included in `icons/LICENSE`. `icons.json` contains the corresponding original SVG path data converted for native WPF rendering.
