# DeskDots

Windows 桌面小组件：Dot 回复、本机 Codex 任务状态与 Codex 额度。

## 运行

首次从源码使用时，先按下方「构建和验证」编译，生成 `dist/DeskDots.exe`。

双击 `dist/DeskDots.exe`。Windows 10/11 x64，使用系统自带 .NET Framework 4.7.2+、WPF 和 winsqlite3，不需要 Node、Python 或 API Key。常驻窗口为 320 × 128 的小卡片，默认放在桌面右上角。左侧为图标操作，右侧为剩余额度大字。支持拖动、托盘和 F5 刷新；Esc 收进托盘，双击托盘图标恢复，右键托盘可退出。常驻卡片不占任务栏。

首次运行会继承 CODEX_HOME 和本机 Codex CLI 路径，写入组件自己的设置；也可以在设置里指定。通过资源管理器启动时如果没有 CODEX_HOME 环境变量，需要选择实际 Codex 数据目录。组件不修改 Codex 配置，不启动模型任务，不消耗模型推理额度，不自动设置开机启动。

界面采用石墨灰底色与少量蓝色强调，配套 Geist 字体和 Phosphor 矢量图标。移动或分发程序时，请保留 exe 旁的 `assets` 目录；字体只供应用使用，不安装到系统。消息、任务、设置图标均支持点击展开，再点同一图标收起；点击不同图标切换对应详情。任务和设置通过图标按需打开，详情宽度与主卡片一致（320），高度随实际内容收缩；长列表达到上限后才滚动。默认不显示列表。未点击时，卡片和回复窗口位于普通应用窗口下方；点击后可正常交互，失去焦点后恢复沉底。输入错误直接显示在设置字段附近。

## 三类信息

- **Dot 回复**：只显示当前 Dot 的 assistant 回复。需要启用一次本机发布通道，见 [Dot 接入说明](integration/DOT-SETUP.md)。无法自动获取 Dot 云端历史消息。没有新回复时不显示消息列表或空状态。新回复在主卡片下方出现独立卡片，停留 10 秒后用 0.5 秒淡出关闭；额度卡片继续保留。系统关闭动画时直接关闭消息卡片。已有旧回复不会在启动时重放，点击消息图标可重新查看最新回复。
- **任务**：显示仍在进行，以及过去 72 小时活跃的本机 Codex 任务，只读取标题、状态和时间，不读取普通聊天正文；点击任务图标查看列表，再通过 `codex://threads/<id>` 返回主应用。Dot Activity 缓存可用时也会加入并标记来源。暂不列出未同步到本机的远程/云端任务。
- **额度**：通过官方 Codex App Server 的 `account/rateLimits/read` 实时查询。右侧大字显示主窗口的剩余比例；悬停在数字或进度条上查看所有返回窗口及重置时间。空值显示破折号；缓存和断线状态显示在悬停提示中。不会自动兑换重置次数。

本机任务状态来自 Codex 的持久记录，不能精确判断仍未退出的进程或待审批状态；异常退出时 `inProgress` 可能滞后，因此标成「进行中（记录）」。本机读取每 8 秒刷新，额度由独立计时器每 60 秒刷新；点击刷新图标可立即请求，网络和服务端统计可能带来延迟。状态点用更鲜明的蓝色表示本机读取正常；本机读取或额度同步异常时为红色，悬停可看错误。断网会在额度请求失败后反映到红点，不会被后续本机读取成功覆盖。时间按 Windows 本地时区显示。账户额度在服务端统计，可能略有延迟。

## 数据与隐私

默认仅写 `%LOCALAPPDATA%\DeskDots`：设置、裁剪后的额度缓存、Dot 回复文件和接入说明。可用 `--data-dir <绝对路径>` 改为便携目录。Codex 的全局状态和 SQLite 数据库只读打开，使用现有登录状态调用 CLI，不读取或保存 auth.json、访问 token、Cookie。额度查询会让官方 CLI 正常维护自己的内部状态数据库。

非官方第三方组件。Dot 本地缓存、Codex 数据库结构与 App Server 仍可能随版本变化；读取失败会明确显示错误。当前适配本机 Codex CLI 0.165.0-alpha.1.2 和桌面版 26.1023。普通聊天正文不会进入组件的 Dot 回复区。

## 构建和验证

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Test
```

编译器为 Windows 自带 .NET Framework csc；构建不下载依赖。测试覆盖账号隔离、消息来源/角色过滤、错误线程拒绝、幂等发布、多额度桶、缺失额度、时间戳、旧消息不重放和新消息去重。`--ui-smoke <报告路径>` 离线验证真实卡片尺寸、非置顶、不抢焦点与十秒通知关闭，不读取真实消息。

只读诊断（写出数量和额度，不包含回复正文或登录数据）：

```powershell
& '.\dist\DeskDots.exe' --diagnose 'D:\path\diagnostics.json'
```

`--mcp` 启动可选 stdio MCP 桥接；`--publish-file` 发布 Dot 回复。详见接入说明。
